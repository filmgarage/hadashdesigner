# Fotolijst add-ons

Home Assistant add-ons voor een digitale fotolijst met Fully Kiosk.

## Add-ons

- **HADashDesigner** (`hadashdesigner`): bewerkt HADashboard-bestanden (`.dash`) in de AppDaemon-map.

## Installeren in Home Assistant

1. Ga naar **Instellingen > Add-ons > Add-on store**.
2. Kies rechtsboven **Repositories** en voeg de URL van deze repository toe.
3. Installeer de add-on uit de store.
